# 光体•名无界

> 面向中小企业主与创业者的「双引擎可见性 SaaS 工作台」——一个后台同时看清你的品牌在 **传统搜索（Google/Baidu 等）** 和 **AI 搜索（ChatGPT / 豆包 / Perplexity / Gemini / Copilot / Grok / Google AI Overviews）** 里被不被看见。

## 双引擎底座

- **传统搜索可见性（SEO）**：基于开源 [OpenSEO](https://github.com/every-app/open-seo)（MIT）的数据能力。
- **AI 搜索可见性（GEO/AEO）**：基于开源 [GEO/AEO Tracker](https://github.com/danishashko/geo-aeo-tracker)（MIT）的 7 大 AI 平台监测能力。

两者均 MIT 协议、可自托管、数据自有。

## 五大功能模块

| 模块 | 说明 |
| --- | --- |
| A 传统搜索 SEO | 关键词排名、排名趋势、外链、站点技术审计 |
| B AI 搜索 GEO | 7 平台可见性评分（含豆包）、引用分析、竞品 Battlecard、AEO 审计 |
| C 双引擎看板 | 谷歌排名 + AI 可见性统一周报一句话概览 |
| D 行动优化 | llms.txt 一键生成与下载、按行业适配的 JSON-LD 结构化数据建议、引用建设清单 |
| E 报告分享 | 老板视图、HTML 周报导出 |

## v0.4 更新（真实性 / 有效性 / 实时性 / 通畅性）

- **【真实】新增「真实站点体检」**：浏览器直接抓取 llms.txt、robots.txt、sitemap.xml 与首页 HTML 并本地解析，输出 10 项检查与「技术就绪分」。**不需要任何 API Key**，结果可自行复核；跨域被拦时提供手动粘贴兜底，仍由同一套解析器分析，不伪造数据。robots.txt 会逐项判定是否屏蔽 7 个主流 AI 爬虫。
- **【有效】行动闭环自动验证**：llms.txt / robots.txt / sitemap / JSON-LD 四项由真实抓取自动判定，改完重跑即变绿。
- **【实时】数据新鲜度**：记录每次检测时间，显示「X 分钟前」与新鲜度徽章（新鲜 / 建议更新 / 已过期）、建议复核日期，报告页新增检测时间轴（时间 + AI 可见性 + 排名 + 技术就绪分 + 抓取覆盖度）。
- **【通畅】哈希路由**：…，支持浏览器前进后退、刷新后停留在原视图、各视图独立记忆滚动位置；弹窗焦点陷阱与关闭后焦点归还、toast 队列化、回到顶部按钮。
- **数据来源透明**：落地页新增「数据来源与更新频率」表，工作台每条数据带「真实抓取 / 演示数据」标签，报告页附数据来源与时间戳对照表。
- **内容补充**：常见错误案例（4 个高频坑，含正确/错误对照）、服务边界（做什么 / 不做什么）。
- **存储升级**：localStorage 键升至 `mwj.store.v4`，自动兼容迁移 v3 旧数据。

## v0.3 更新（实际操作性版）

从「看数据」升级为「能动手做完」，重点补齐使用者视角下的操作断点：

- **打通最后一公里**：llms.txt 生成后不再是死文本 —— 提供 **三步上线指引**、**5 类托管环境**（静态托管 / WordPress / 宝塔 / Nginx / 对象存储）的逐步说明与可复制命令、**在线验证按钮**（真实发起请求检查 `https://域名/llms.txt` 是否可访问，并检查内容是否含品牌名）。
- **数据持久化**：站点列表、检测快照、勾选进度、自定义关键词、竞品全部存入浏览器本地存储（localStorage），刷新不丢；支持多站点切换与一键清空。
- **真正的「改完复查」**：每次「重新检测」写入历史快照，看板显示与上次的真实对比（AI 可见性变化、排名变化）。
- **可编辑**：关键词可增删（自建词标记）、竞品可填真实名字（Battlecard 随之更新）、引用机会可增删并勾选。
- **指标会说话**：排名 / 难度 / 健康分 / 可见性分全部附阈值评级与「这意味着什么 + 怎么改」提示；站点审计每项给出修复动作。
- **优先级行动清单**：按 P0/P1/P2 + 影响 / 难度 / 预计耗时排序，直接回答「先做哪件」。
- **导出能力**：CSV（含 BOM，Excel 打开中文不乱码）、浅色可打印 HTML 周报（Ctrl+P 存 PDF）、微信分享文案。
- **内容补充**：5 分钟上手、11 条术语词典（全文可点击查询）、三个行业的可执行剧本、更新日志、帮助与联系。
- **无障碍**：侧栏改为语义化 button 与 tablist、键盘可达、`focus-visible` 焦点态、跳过导航链接、`aria-label` / `role` 标注。
- **域名校验**：实时格式校验 + 自动归一化（去除 `https://` 与前缀路径）。

## 技术说明

当前为 **内测演示版**：前端已完整实现全部交互与可视化，数据层为按行业参数化生成的演示数据（工作台内已明确标注），真实 API 集成点已预留于 `assets/app.js` 的 `fetchBackend()`。接入真实 API Key（DataForSEO / Bright Data / OpenRouter）后即可切换为生产数据。
